# Sample photography

Hotel/room photos are demonstration images downloaded from Unsplash's image CDN. The properties are fictional; the photos are illustrative. Source photo identifiers:

- Verde / homepage: photo-1566073771259-6a8506099945
- Amihan: photo-1571896349842-33c89424de2d
- Escolta: photo-1542314831-068cd1dbfeeb
- Luntian: photo-1582719508461-905c673771fd
- Room interior: photo-1611892440504-42a792e24d32

Files are stored locally in database/sample_images, copied into backend/media by the seed, and the hero copy is in frontend/public/hero.jpg. The application does not depend on Unsplash at runtime. The modern map uses OpenFreeMap/OpenMapTiles data from OpenStreetMap; its basic fallback uses OpenStreetMap tiles. Attribution is displayed on the map.

Calapan sample conversion: the same stock photographs illustrate fictional local listings. They are not claimed to depict actual Calapan establishments. Approximate map center follows the city government reference: https://beta.cityofcalapan.gov.ph/barangays/ .

Vector map setup: https://openfreemap.org/quick_start/ . Map engine: https://maplibre.org/maplibre-gl-js/docs/ . Google Maps links open the public map separately; the application does not embed the paid/custom Google Maps JavaScript service.
